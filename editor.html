Categories

Stored inside the GeoJSON file itself, so the app picks up your changes on its next refresh — nothing else to keep in sync. Emoji, label and colour are editable; the id is fixed once created, because places reference it.

Google Places API key

Optional. Without it, adding from a URL gives you name and coordinates only. With it, the editor fetches address, rating, opening hours, phone, website and Google's category.

Stored in this browser's localStorage — never written into the file or the source. Restrict the key to the Places API in the Cloud Console, and set a daily quota cap so a mistake cannot run up a bill.

Import and append

Paste a GeoJSON FeatureCollection, or choose a file. Existing places are never overwritten — anything already present (matched on placeId) is skipped, and only genuinely new features are appended.

Add from a Google Maps URL

Paste the long URL from your browser's address bar — not a maps.app.goo.gl share link. Short links have to be followed to resolve, and Google blocks that from a browser, so they cannot be read here.

A URL yields name, coordinates and place ID only. Rating, hours and Google's own category are not in the URL — fill in category, notes and tags yourself after adding.
